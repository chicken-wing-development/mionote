mio note 1.0.0 — 水筆（みお）— Windows 11 ポータブル版

ツールバーの「©」またはF1で「バージョン情報・コピーライト」を開けます。
元のアイコンの絵を大きく表示します。

動作環境
  Windows 11。ARM64版はSnapdragonなど、x64版はIntel／AMD向けです。

起動方法
  1. CPUに合ったZIPをWindows端末へコピーします。
  2. ZIPを右クリックして「すべて展開」します。
  3. 展開したフォルダー内の MioNote.exe をダブルクリックします。

インストールは不要です。Rust、Visual Studio、.NET、WebView2、
VC++再頒布可能パッケージの追加インストールも不要です。
実行時はWindows標準のAPIを使います。
USBからでも起動できます。設定の保存のため、フォルダー全体を書き込み可能な場所へ置いてください。

操作
  ペンでノートに書きます。初期設定は「細・筆圧オフ・罫線間隔は標準」です。
  「線幅」の細・中・太で、ペンの太さを3段階から選びます。
  ペン先のアイコンで筆圧をオン／オフにします。青色がオン、オフでは均一の太さで書けます。
  線幅と筆圧の変更はこれから書く線に反映されます。既存の筆跡は変わりません。
  「罫線間隔」の横線アイコンで、左から狭・標準・広に切り替えます。既存の筆跡は残ります。
  線幅・筆圧・罫線間隔は変更時にバックグラウンドで自動保存し、次回起動時も同じ設定で使えます。
  連続した変更は最新の設定にまとめ、終了時は最後の保存を完了してから閉じます。
  保存先はEXEの隣の data\settings.ini です。mio-note.portableも一緒に保持してください。
  設定を引き継ぐときは、アプリ終了後に以前のsettings.iniをdataフォルダーへコピーします。
  フォルダーごと移動すると設定も引き継ぎます。保存に失敗しても別の場所へ黙って切り替えません。
  読み込みに失敗した場合は初期値で起動し、保存に失敗した場合は画面で知らせます。
  マウスの左ドラッグでも書けます。
  筆圧の隣の消しゴムアイコンを押すと消去モードになり、もう一度押すとペンに戻ります。
  青色が消しゴムオンです。ペンへの切り替えボタンはありません。
  各ボタンにマウスを重ねると説明が表示されます。Eで消しゴムをトグル、Pでペンに戻れます。
  消しゴムはストローク単位で線を消します。
  対応ペンの消しゴム側も使用できます。
  指による描画は無効です。

線幅と罫線間隔の基準
  線幅の「細」はv0.2.0の「中」と同じ太さです。
  罫線間隔の「標準」はv0.2.0の「広」と同じ間隔です。
  他の段階もそれに合わせて変更しています。

ノートの保存・読み込み
  「保存」またはCtrl+Sで、筆跡を .inknote ファイルに保存します。初回は保存先を選びます。
  「開く…」またはCtrl+Oで読み込み、追記や消しゴム編集ができます。
  「別名で保存…」またはCtrl+Shift+Sで別のファイルへ保存します。
  タイトルの * は未保存の変更です。閉じるときや別のノートを開くときに保存するか確認します。
  読み込みに失敗した場合は現在の筆跡を残します。
  筆跡の保存は手動です。線幅・筆圧・罫線間隔のユーザー設定は変更時に自動保存します。
  .inknote の中身はZIPで、document.json とページごとの pages/0.isf などです。
  全ページの筆跡・筆圧・色・線幅、用紙サイズ・向き・罫線間隔を保存します。
  保存座標は画面の大きさやDPIから独立しています。
  0.6.0以前の単一ページ形式には対応していません。
  ノートファイルを MioNote.exe へドラッグして開くこともできます。拡張子の関連付けは行いません。

用紙とページ
  初期用紙はA4縦です。A4・A5・B4・B5をページごとに選べます。
  B4・B5は日本のJIS規格です（B4: 257×364 mm、B5: 182×257 mm）。
  「縦」「横」のボタンで向きを切り替えます。
  「+ ページ」で末尾に白紙を追加します。現在の用紙・向き・罫線間隔を引き継ぎます。
  「<」「>」で前後のページへ移動します。表示していないページの筆跡も保持します。
  「削除」で現在のページを削除できます。確認で「はい」を選ぶと筆跡ごと削除します。
  削除後は次のページを表示し、末尾を削除したときは前のページを表示します。
  最後の1ページは削除できません。削除は取り消せません。変更はCtrl+Sで保存します。
  起動時は「横幅」で、用紙の幅をウィンドウいっぱいに表示します。
  「全体表示」でページ全体を一度に確認できます。
  「＋」「−」で25〜400%に拡大・縮小できます。Ctrl+＋／Ctrl+−、Ctrl+ホイールも使えます。
  Ctrl+1は横幅に合わせ、Ctrl+0は全体表示です。横幅・全体表示はウィンドウの大きさに追従します。
  現在の倍率が表示されたボタンをクリックするか、Ctrl+2で100%に戻します。
  はみ出す部分はスクロールバーやホイールで移動します。Shift+ホイールや横ホイールで横へ移動します。
  PageUp／PageDownで上下へ移動し、Homeは上端、Endは下端です。
  拡大してスクロールした位置にも書けます。表示だけの変更ではノートは未保存扱いになりません。
  表示倍率とスクロール位置は保存せず、次回起動時は横幅表示に戻ります。
  用紙変更で筆跡が収まらない場合は比率を保って縮小します。自動では拡大しません。

書き出し
  「書き出し ▾」から形式と出力範囲を選びます。
  PDFは全ページを順番に1つのファイルへ出力します。Ctrl+Eでも出力できます。
  用紙ごとの実寸・縦横と罫線を反映し、空白ページも含めます。
  印刷はPDF閲覧ソフトで100%・実際のサイズなどを選ぶと実寸になります。
  筆跡と罫線はベクターです。筆圧ありの線は幅へ変換して近似します。
  筆圧の補間や端部が画面と異なる場合があります。元の筆圧情報は .inknote に保持します。
  PDFを出力してもノートの変更は保存済みになりません。編集用には .inknote も保存してください。
  PNGは現在のページを300dpiで出力します。線の縁を滑らかに描画します。
  SVGは現在のページを実寸mm・ベクターで出力します。
  PNG・SVGの全ページZIPを選ぶと、page-0001.png / page-0001.svgなどの連番で格納します。
  空白ページも含めます。ZIPを展開すると各ページを個別に使えます。
  背景は白で、罫線を含めます。筆圧ありの線はどの形式でも幅への近似です。
  書き出しても編集用ノートの変更は保存済みになりません。.inknoteも保存してください。
  PDF・PNG・SVGの取り込みは未実装です。0.7.0の.inknoteはそのまま開けます。

重要
  入力値・保存処理・DLL読み込み・依存関係の安全性を見直した版です。
  形式はバージョン2を継続しますが、過大なデータや不正な数値は拒否します。
  ノートは全体128 MiB、ISFは1ページ8 MiB・合計64 MiB、筆点は全体200万点までです。
  書き出しは全体512 MiBと描画処理の上限を設けています。失敗時は以前の保存先を保持します。
  詳細な指摘・制限・検証結果は security/security-review-20261027.md を参照してください。
  Undo、ページの並べ替えは未実装です。
  実際のペンの追従感、筆圧、手のひらを置いたときの挙動を確認するための版です。
  この実行ファイルにはコード署名を付けていません。

診断
  通常起動ではログファイルを作成・更新しません。
  診断するときだけ、EXEのあるフォルダーでPowerShellから次のように起動します。

    $env:MIONOTE_DIAGNOSTICS = '1'
    & .\MioNote.exe

  診断時はdataフォルダーに最大1 MiBの mio-note.log を作成します。
  初期化・ツール切り替え・ストローク数を記録し、筆跡の座標は保存しません。
  ログは診断起動ごとに更新します。通常起動へ戻すには新しいPowerShellから起動してください。
  起動処理の時間と、ペン先から表示までの遅延は別の指標です。
