# 固定用紙・ページ制・PDF出力

0.7.0の初期用紙はA4縦です。A4・A5・JIS B4・JIS B5の縦横をページごとに選べます。
「+ ページ」は末尾に追加し、用紙・向き・罫線間隔は表示中のページから引き継ぎます。
「<」「>」で移動し、表示していないページの筆跡も保持します。
0.9.0では初期表示を横幅に合わせます。拡大縮小・スクロール・全体表示は[表示操作](view-controls.md)を参照してください。
0.10.0では「削除」で現在のページを確認後に筆跡ごと削除できます。
削除後は次のページへ移動し、末尾の場合は前のページへ移動します。最後の1ページは残します。
確認は「いいえ」が初期選択です。削除は取り消せません。ノートを保存するとファイルにも反映します。
PDF・PNG・SVGにも残っているページを順番に出力します。ページの並べ替えは未実装です。

用紙を変更するとき、筆跡が新しい用紙に収まらない場合だけ比率を保って縮小します。
自動拡大はしません。縮小後に大きい用紙へ戻しても筆跡の大きさは戻りません。
画面の罫線もDIPから毎行の位置を計算し、端数の丸めがページ下部へ累積しないようにしています。

## PDF

「PDF出力」またはCtrl+Eで、先頭から全ページを1つのPDFへ出力します。
ページごとの用紙の実寸をMediaBoxへ設定し、空白ページも含めます。
画面の周囲の余白やツールバーは入りません。背景は白で、罫線と赤い余白線を出力します。
実寸で印刷する場合は、PDF閲覧ソフトで「実際のサイズ」などの100%設定を使います。

外部PDFランタイム・フォント・プリンタードライバーを使わず、Rustの小さなライターが出力します。
筆跡はWindows Inkの描画セグメントをベクターの線へ変換します。
通常の均一幅の線は円形の端・結合を持つパスで、筆圧ありの線は細かい線幅の変化で近似します。
筆圧の補間や端部はWindows Ink固有の描画と差が生じる場合があります。
PDFには編集用の筆圧データやISFを埋め込まないため、再編集には`.inknote`を保存してください。

出力はファイルワーカーで行います。書き込みの失敗・キャンセルでノートの保存先や変更状態を変えません。
出力先は`.pdf`の拡張子を要求し、同じフォルダーの一時ファイルを完成させてから置き換えます。

## 確認

Windows ARM64で13件の自動テストが通過しました。
設定保存、DPI変換、ISFの属性・筆圧、異なる用紙の複数ページの保存・再読み込み、
旧形式と不正な用紙の拒否、失敗した保存での元ファイル保持を確認しています。

PDF検証ではA4・A5・JIS B4・JIS B5の縦横8ページと空白のA4ページを出力しました。
Popplerで全ページを画像へ描画し、筆跡・罫線・余白線・ページ順を視覚確認しています。
独立したPDFパーサーでも9ページを読み、MediaBoxをmmへ換算して各用紙と0.001mm以内で一致しました。
筆跡の平行移動を一度だけ適用し、画面に収めた倍率がPDFへ二重に反映されないことも検証しています。

実機のペン追従遅延・筆圧・手のひらの挙動、高速筆記での欠けは別途実機確認が必要です。
