# 拡大縮小・ページの表示

0.9.0の初期表示は「横幅に合わせる」です。縦長の用紙は下へスクロールして書きます。
表示倍率は用紙の96 DPI座標を基準にし、モニターのDPIも反映します。

| 操作 | ボタン・入力 |
| --- | --- |
| 拡大・縮小 | 「＋」「−」、Ctrl+＋／Ctrl+−、Ctrl+ホイール |
| 横幅に合わせる | 「横幅」、Ctrl+1 |
| 全体を表示 | 「全体表示」、Ctrl+0 |
| 100%に戻す | 現在の倍率のボタンをクリック、Ctrl+2 |
| 縦へ移動 | ホイール、縦スクロールバー、PageUp／PageDown |
| 横へ移動 | Shift+ホイール、横ホイール、横スクロールバー |
| 上端・下端 | Home／End |

手動ズームは1回ごとに1.2倍またはその逆数、範囲は25〜400%です。
ボタン・キーでは表示領域の中央を、Ctrl+ホイールではポインターの位置を中心に拡大縮小します。
0.9.1から倍率表示はボタンになり、クリックで100%へ戻せます。Ctrl+2でも同じ操作ができます。
100%へ戻すときも表示の中心を保ち、以後はウィンドウを広げても100%のまま表示します。
ページ端ではスクロール可能な範囲へ補正するため、中心位置が移る場合があります。
横幅・全体表示はウィンドウや用紙の大きさに追従し、この自動倍率には手動ズームの制限を使いません。
横幅・全体表示を選ぶとスクロール位置を上端へ戻します。

ページ追加・移動・用紙変更・ノート読み込みでも上端へ戻し、表示モードは引き継ぎます。
表示モードとスクロール位置はファイルへ保存しません。次回起動は横幅表示です。
表示の変更だけでは未保存マークは付きません。PDF・PNG・SVGは常に用紙全体を実寸で書き出します。

表示操作は既存の3行のツールバーの空きへ配置し、横幅が800 DIP未満のときだけ4行目へ折り返します。
Win32のスクロールバーと、ページを切り抜く親ウィンドウを使い、新しいランタイムは追加しません。
スクロールではページの子ウィンドウの位置だけを動かし、筆跡の変換・複製やInkキューへの処理追加をしません。
ズーム時だけ、既存のInkスケール処理で筆跡とこれから書くペンの幅を同じ倍率へ変更します。

自動テストで、用紙4種×縦横×100・150・200%のモニターDPI、幅・全体の表示、
ズーム中心の保持、上下左右の端までの移動、25〜400%の制限を確認します。
反復ズーム後のISF保存・復元でも、筆跡の座標・線幅・筆圧を確認しています。
